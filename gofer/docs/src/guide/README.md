# Getting Started

Let's start by setting up our first Gofer pipeline!

This guide runs everything on your own machine, so all you need is Linux, Docker, and Go (or Rust, if you'd rather
write your pipeline in that). By the end you'll have:

1. [Installed Gofer](./installing_gofer.md).
2. [Started the Gofer server locally](./running_the_server_locally.md) in development mode.
3. [Written a pipeline configuration](./create_your_first_pipeline_configuration.md).
4. [Registered that pipeline with Gofer](./register_your_pipeline.md).
5. [Started a run](./start_a_run.md) and looked at its results.
